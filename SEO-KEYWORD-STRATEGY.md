# SANAR IT Solutions: search intent and keyword plan

This plan groups phrases by likely intent and fit with the current one-page site. It does not report search volume, keyword difficulty, or ranking forecasts. Those metrics require a keyword research account or a specified market dataset; none is configured for this project.

## Homepage: local commercial discovery

Target one natural cluster in the title, description, introductory copy, and organization details:

- Software development for Hyderabad businesses
- Software solutions in Hyderabad
- Software development services Hyderabad
- IT company in Hyderabad

These are service-provider discovery queries with commercial intent. The company says it serves Hyderabad and global clients; the site does not claim a Hyderabad office or street address.

## Service cards: specific commercial needs

| Service | Primary phrase | Supporting phrases |
|---|---|---|
| Website Development | Website development | Business website development; corporate website development; custom website development |
| Cross-Platform App Development | Cross-platform app development | Android and iOS app development; custom mobile application development |
| Web Application Development | Web application development | Custom web application development; business web applications; dashboard development; SaaS development |
| UI/UX Design | UI/UX design services | Website UI/UX design; application interface design |
| AI Automation | AI automation services | Business process automation; AI integration services; intelligent workflow automation |
| Custom Software Development | Custom software development | Business software solutions; tailored software development |

These phrases indicate solution research or vendor selection. Current card copy uses relevant terms naturally. Do not force every variant into every section.

## Brand and navigational intent

- SANAR IT Solutions
- SANAR IT Solutions Pvt Ltd
- SANAR IT Solutions Hyderabad
- SANAR software solutions
- SANAR IT services

Use the consistent legal/brand name in metadata, structured data, logo alt text, and contact details. Avoid creating separate brand landing pages for minor spelling variants.

## Prioritization and next research

1. Homepage: branded discovery plus software development for Hyderabad and global businesses.
2. Six service cards: the service-specific terms above.
3. Build dedicated service pages only when each page can include distinct scope, process, examples, and useful answers to buyer questions.
4. Review Search Console queries after verified ownership and indexing; then use Keyword Planner or another documented keyword dataset to assess volume and difficulty.

The relative priority above is based on relevance and commercial intent, not claimed keyword volume or measured difficulty. No neighborhood pages, testimonials, ratings, or local address claims have been created.
